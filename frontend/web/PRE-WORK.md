# 大屏前端依赖准备

## 基础依赖

| 库 | 用途 |
| --- | --- |
| `vue` | 大屏页面、组件和生命周期管理 |
| `typescript` | 类型约束，与管理端及后端接口共享数据结构 |
| `vite` | 本地开发与生产构建 |
| `vue-router` | 等待页、抽奖页、结果页等页面路由 |
| `pinia` | 活动、大屏配置和开奖状态管理 |
| `axios` | HTTP 接口请求 |

## 动画与渲染

| 库 | 用途 |
| --- | --- |
| `pixi.js` | 金色纸片、丝带、粒子等高性能 2D 动画 |
| `three` | 透明球机、灯光、材质和其他 3D 大屏模板 |
| `gsap` | 编排预热、抽取、收集、停顿和统一揭晓等动画时间线 |

## 按模板引入

| 库 | 用途 |
| --- | --- |
| `@dimforge/rapier3d-compat` | 为透明球机提供球体碰撞、重力和气流扰动等物理模拟 |
| `qrcode` | 在等待参与页面生成员工扫码入口 |
| `howler` | 管理背景音乐、抽奖音效以及音量和播放状态 |

WebSocket 使用浏览器原生 API，不额外引入通信库。

## 签到大屏背景模板记录

背景由一层线性渐变作为底色，再叠加两层径向渐变形成局部光晕。装饰光束、底部椭圆和中央柔光分别通过伪元素及独立元素绘制。后续管理端选择模板时应保存模板编码，大屏根据编码应用完整样式，不建议只保存一个背景色值。

### 红色庆典

- 建议编码：`celebration-red`
- 强调色：`#ef4444`
- 基础渐变：`radial-gradient(ellipse 64% 68% at 57% 47%, rgba(139, 18, 18, 0.68) 0%, rgba(91, 8, 13, 0.76) 46%, rgba(43, 4, 9, 0.92) 74%, rgba(15, 2, 5, 0.98) 100%)`
- 右上暖光：`radial-gradient(circle at 74% 4%, rgba(226, 83, 38, 0.13), transparent 31%)`
- 斜向光束：`linear-gradient(112deg, transparent 20%, rgba(255, 202, 154, 0.08) 49%, transparent 72%)`
- 底部椭圆：边框 `rgba(255, 184, 113, 0.16)`，光晕 `rgba(255, 68, 45, 0.16)`
- 中央柔光：`rgba(255, 154, 115, 0.08)`，模糊半径 `80px`

最终叠加顺序：

```css
background:
  radial-gradient(ellipse 64% 68% at 57% 47%, rgba(139, 18, 18, 0.68) 0%, rgba(91, 8, 13, 0.76) 46%, rgba(43, 4, 9, 0.92) 74%, rgba(15, 2, 5, 0.98) 100%),
  radial-gradient(circle at 74% 4%, rgba(226, 83, 38, 0.13), transparent 31%),
  #1c0307;
```

### 暗金典礼（方案记录，当前未启用）

- 建议编码：`ceremony-gold`
- 深棕金：`#3a240f`
- 暖金：`#b8782f`
- 主金色：`#d1a052`
- 香槟高光：`#f0c878`
- 局部亮金：`#fff0bf`
- 基础渐变：`linear-gradient(135deg, #080706 0%, #100c09 55%, #080706 100%)`
- 丝带附近环境光：`radial-gradient(ellipse 50% 35% at 67% 82%, rgba(139, 83, 27, 0.15), transparent 78%)`
- 底部丝带：Three.js 使用 Catmull-Rom 曲线采样生成连续带状网格，每条曲线只创建一个 `BufferGeometry` 和一个 `ShaderMaterial`。
- 丝带 Shader：通过 UV 横向坐标计算柔和透明边缘和两侧金色高光，通过 UV 纵向坐标与时间参数生成缓慢移动的局部亮带。
- 默认丝带：3 层，速度 `0.055`，整体透明度 `0.94`。主丝带约为 146px，次丝带约为 84px，远景丝带约为 49px（以 1080p 为基准）。
- 辉光层：每条主体丝带下方叠加一层宽度约为 `1.22` 倍的低透明度 Additive Blending 网格，只增强局部高光。
- 默认粒子：110 个，速度 `0.035`；低性能模式最多 50 个。
- 性能模式：普通模式设备像素比最高为 2，低性能模式最高为 1.25，同时降低曲线采样段数并关闭抗锯齿。

最终叠加顺序：

```css
background:
  radial-gradient(ellipse 50% 35% at 67% 82%, rgba(139, 83, 27, 0.15), transparent 78%),
  linear-gradient(135deg, #080706 0%, #100c09 55%, #080706 100%);
```
